# 🤖 AI Document Assistant

An AI-powered Document Assistant built with **Python**, **Streamlit**, **LangChain**, **Transformers**, **FAISS**, and **Google Gemini API**. This application allows users to upload documents, ask natural language questions, and receive intelligent answers based on the document content.

## ✨ Features

- 📄 Upload PDF, DOCX, and TXT files
- 🤖 AI-powered question answering
- 🔍 Semantic search using FAISS
- 🧠 Document embeddings with Transformers
- ⚡ Fast and accurate responses using Google Gemini
- 🎨 Modern and responsive Streamlit interface
- 🔒 Secure API key management

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Document-Assistant.git
cd AI-Document-Assistant
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Create a `.env` file

```env
GOOGLE_API_KEY=your_api_key_here
```

### 4. Run the application

```bash
streamlit run app.py
```

---

## 📖 How to Use

1. Enter your Google Gemini API Key.
2. Upload a PDF, DOCX, or TXT document.
3. Type your question in the input box.
4. Click **Generate Answer**.
5. Get AI-generated responses based on your uploaded document.
